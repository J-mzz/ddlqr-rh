# Robust Data-Driven Receding-Horizon Control for LQR With Input Constraints

This repository contains the code for the paper:
**Robust Data-Driven Receding-Horizon Control for LQR With Input Constraints**

## Usage
Run ddlqr_2d and ddlqr_4d to reproduce the 2d and 4d example in the paper, respectively.
Each script generates the corresponding simulation results reported in the paper.
